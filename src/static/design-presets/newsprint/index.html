01 · The system

What the preset decides

i

A visible grid

Adjacent cells share a single hairline rather than each drawing their own. Decide the border per side, or every junction gains a 2px line and the page looks misprinted.

ii

Four faces, four jobs

A display serif for headlines, a reading serif for body, a sans for interface, a mono for data. Each has a job; none is used for mood.

iii

One red

A signal, not a colour scheme — a badge, a CTA, an underline. On the off-white it measures 5.54:1 and clears AA; on black it is 3.11:1, so it never appears there.

02 · In detail

Density is a feature, not a flaw.

Fig. 1.1 · The measure

Most web layouts are built to breathe. This one is built to inform: tighter padding, shared rules and a narrower measure put more on the page without making it harder to read, which is exactly the trade a newspaper makes every day.

The justified column is part of that. Set with hyphenation and a sensible measure it reads as a printed page rather than a web page; set without either it produces rivers of white and looks broken, which is why it is applied only above the tablet breakpoint here.

03 · Method

Four moves

I

Rule the grid

Decide the columns and let the borders show where they fall.

II

Set the scale

A display serif far above a reading serif. The gap is the hierarchy.

III

Lay the texture

Dots, graph grid, halftone — or the page reads as blank stock.

IV

Place the red

Once or twice, as a signal. Never on this band.

05 · Queries

Frequently asked

Is this a mock-up or the real thing?
A specimen, hand-built to the preset's specification so the style can be seen whole rather than as a thumbnail. The preset itself is a set of WordPress Theme Settings; a generated site inherits the palette, the type and the structure. The print detail on this page — the drop cap, the ticker, the halftone texture — is still being folded into the preset and is not all emitted automatically yet.
Why is the red missing from the dark band?
Because it fails there. The editorial red measures 5.54:1 on the off-white and clears AA comfortably, but only 3.11:1 against the black. On the inverted section the accent becomes white instead. It is the one rule in this palette that is a constraint rather than a taste.
Does the density survive a phone?
Yes, with one change: the vertical rules come off and the horizontal ones stay, so a single column does not end up with a stray line down its side. Tap targets stay at 44px regardless — density must never shrink the thing you are trying to press.
