What the preset decides

Three rules

01

Fill or type, never both

A colour is either a fill with the void on it, or it is type on the void. All five work beautifully as type; only the purple carries a white label.

02

The stack has no blur

Two or three solid offsets in different accents, so an element looks printed three times in misregistration. One soft shadow and it is an ordinary card again.

03

The paragraph stays plain

Everything around the body text can shout. The body text itself is white on the void at nineteen to one, in a quiet face, because the noise has to be survivable.

Questions

Frequently asked

Is this a mock-up or the real thing?
A specimen, hand-built to the preset's specification so the style can be seen whole rather than as a thumbnail. The preset itself is a set of WordPress Theme Settings, and a generated site carries the void, the five accents, Unbounded over DM Sans, the zero radius and the stacked hard shadow. The dot field, the gradient bar and the misregistration layouts are markup, so a section that wants them still asks for them.
Isn't maximalism just an excuse for bad contrast?
It is the opposite, and the specification says so: chaos in the decoration, order in the contrast. Loud colour only reads as loud if it is legible — four of these five fills carry dark text, and that is what lets the page be as noisy as it is.
Why only one dominant colour per view?
Because five accents at equal weight produce mud rather than maximalism. Each section here has one colour leading and the others supporting, which is what keeps the noise composed rather than random.
