What the preset decides

A kit of three

01

Scale

Eight to ten times between the headline and the body. The single decision that makes this style recognisable from across a room.

02

Motion

Marquees that run continuously — and stop completely when the visitor has asked for reduced motion, because that preference outranks a house rule.

03

Inversion

Hover a card and it floods acid yellow with black type, in one step. A gradual fade would read as an apology.

The ratio

Viewport units

The headline above is set in vw, so it fills the screen at any width rather than stepping between fixed sizes.

Numerals as shapes

The figures behind each card are 11rem in the surface tone — graphic elements that happen to be characters.

Body stays large

Eighteen to twenty-four pixels, never sixteen. The contrast of scale only works if the small end is still comfortable.

Questions

Frequently asked

Is this a mock-up or the real thing?
A specimen, hand-built to the preset's specification so the style can be seen whole rather than as a thumbnail. The preset itself is a set of WordPress Theme Settings; a generated site inherits the palette, the type scale and the sharp corners. The marquees, the oversized numerals and the hard inversions are still being folded into the preset and are not all emitted automatically yet.
The marquees stop — isn't constant motion the point?
The source specification does say never to stop them. It also says to wrap them in a reduced-motion guard, and those two cannot both hold. Motion that cannot be stopped is a vestibular hazard, and "it is the style" is not a reason to override someone's stated preference — so under reduced motion the marquees sit still and stay readable.
Why is the body text so large?
Because the ratio only works if the small end is still comfortable. Eight times a sixteen-pixel paragraph is a headline that dominates a body no one wants to read. Starting at eighteen to twenty-four keeps the contrast dramatic and the page usable.
