The system

What the preset decides

Space

Section padding runs to 160px and component padding to 48px. If the page feels too airy, it is probably correct — crowding is what makes a restrained palette read as plain.

Tracking

Uppercase labels at 0.3em beside a 7rem headline. The distance between those two is the whole hierarchy, and body text is never tracked at all.

Line

A single top rule rather than a box, and four fixed vertical lines down the viewport. Structure is drawn with hairlines, never with a shadow.

The detail

Slow is the point.

Motion in this style is not feedback, it is pacing. An image takes 1,800 milliseconds to warm from grey into colour — long enough that a visitor has to rest on it, which is exactly the intention. Colour is a reward rather than a response.

Everything else follows the same clock: interactions at 500ms, colour at 700ms, and an easing curve that decelerates rather than snapping. A 300ms version of this page would not read as faster. It would read as ordinary.

Enquiries

Frequently asked

Is this a mock-up or the real thing?
A specimen, hand-built to the preset's specification so the style can be seen whole rather than as a thumbnail. The preset itself is a set of WordPress Theme Settings; a generated site inherits the palette, the type pairing and the spacing. The editorial detail here — the fixed gridlines, the drop cap, the gold slide, the 1,800ms image reveal — is still being folded into the preset and is not all emitted automatically yet.
Why is the gold almost absent from the light sections?
Because it fails there. Gold measures about 5.2:1 on the charcoal and is comfortable, but roughly 2:1 on the alabaster — below AA for text and below the 3:1 minimum for a focus ring or a stateful icon. On light sections gold is a decorative rule and nothing more; focus and emphasis are charcoal. It is the easiest way to ship an inaccessible version of a style whose accent is already meant to be rare.
Does this survive a phone?
Yes, with two changes. The fixed vertical gridlines and the vertical edge label are desktop-only — at phone width they would crowd the very space the style depends on. Padding steps down but never collapses: the air is the design, not a desktop luxury.
